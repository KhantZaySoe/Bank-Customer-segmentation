# 🏦 Bank Customer Segmentation & Churn Analysis

This project analyzes bank customer data to understand customer behavior and predict churn (whether a customer will leave the bank).

The goal is to identify different customer segments and help the bank improve customer retention strategies.

---

## 🚀 Features
- Customer data analysis and visualization  
- Identify patterns in customer behavior  
- Churn prediction using machine learning  
- Model evaluation and performance comparison  

---

## 🛠 Tools Used
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Scikit-learn  
- Jupyter Notebook  

---

## 📂 Project Structure
- `Churn.ipynb` – Data analysis and model building notebook  
- `Churn_Modelling.csv` – Dataset used for analysis  
- `requirements.txt` – Project dependencies  
- `.gitignore` – Ignored files  
- `README.md` – Project documentation  

---

## ▶️ How to Run

1. Clone the repository  
   git clone 

2. Install dependencies  
   pip install -r requirements.txt

3. Open Jupyter Notebook  
   jupyter notebook

4. Run `Churn.ipynb`
